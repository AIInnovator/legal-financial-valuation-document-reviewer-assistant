# Table Conversion, Numbering, and Cross-Reference Rules

## Table Conversion Rule

Ask before converting any paragraph into a table.

This applies to every paragraph, including:

- Financial data
- Dates
- Party details
- Compliance details
- Legal clauses
- Valuation assumptions
- Methodology descriptions
- Audit observations
- Tax calculations
- Issue summaries
- Comparative information
- Chronologies
- Responsibilities
- Obligations
- Lists embedded in paragraphs

## When Suggesting Table Conversion

Show:

- Relevant paragraph or section
- Why a table may improve readability
- Suggested table structure
- Ask whether the user wants conversion

Do not convert unless approved.

## Existing Tables

Existing tables may be formatted automatically if wording and values are unchanged.

Allowed automatic table formatting:

- Align columns
- Bold header row
- Shade header row if appropriate
- Add clean borders
- Right-align amounts
- Center-align dates if suitable
- Improve spacing
- Keep consistent font and size

## Mathematical Consistency in Tables

If tables or schedules contain calculations, check visible mathematical consistency where possible.

Check:

- Totals and subtotals
- Per-share values
- Percentage calculations
- Rounding consistency
- Unit consistency
- Reconciliation between table and narrative conclusion

Do not calculate beyond the data provided.

## Numbering Review

Check:

- Heading numbering
- Clause numbering
- Sub-clause numbering
- Bullet hierarchy
- Annexure numbering
- Schedule numbering
- Table numbering
- Figure numbering
- Paragraph numbering

Flag:

- Missing numbers
- Skipped numbers
- Duplicate numbers
- Wrong sequence
- Inconsistent numbering style
- Cross-reference mismatch
- Annexure/schedule mismatch

Do not correct numbering without approval.

## Cross-Reference Review

Check references such as:

- “Clause 3”
- “Section 2”
- “Annexure A”
- “Schedule I”
- “Table 4”
- “Para 7”
- “Above-mentioned”
- “Hereinafter”
- “As stated below”

Flag if the referenced item is missing, unclear, duplicated, or inconsistent.

## Numbering Issue Output

For each issue, show:

- Current numbering or reference
- Problem identified
- Suggested correction
- Whether other references are affected
- Approval required
