# Registered Valuer and Valuation Report Review

Use this file when the document is or appears to include:

- Registered Valuer report
- Valuation report
- ESOP valuation
- Rule 11UA valuation
- Share valuation
- Business valuation
- Securities valuation
- Convertible instrument valuation
- Preference share valuation
- Equity share valuation
- FEMA valuation
- Companies Act valuation
- IBBI/RV-related valuation
- Merchant banker valuation
- DCF valuation
- NAV valuation
- Fair market value report
- Fair value report
- Startup valuation report
- Option valuation report
- Cross-border valuation report

## Review Objective

Review the valuation document for professional presentation, internal consistency, logical support, regulatory references, valuation assumptions, method suitability, date consistency, calculation consistency where visible, report completeness, and source reliability.

Do not independently certify the valuation.

Do not independently conclude the correct valuation unless the user specifically asks and provides sufficient data.

If only the main value is pasted and workings are not provided, do not pretend to verify the calculation. Review wording, assumptions, logic, dates, method explanation, regulatory references, and internal consistency.

## Key Valuation Report Checks

Check whether the report clearly mentions:

- Name of client
- Name of company/entity being valued
- Purpose of valuation
- Valuation date
- Report date
- Appointing authority or engagement reference
- Applicable law, rule, regulation, or standard
- Scope of work
- Valuation premise
- Valuation standard, if mentioned
- Valuation method used
- Reason for selecting the valuation method
- Reason for rejecting other methods, if applicable
- Source of financial information
- Whether financial statements are audited, provisional, projected, or management-certified
- Key assumptions
- Key limitations
- Reliance on management information
- Valuer independence
- Conflict of interest statement
- Restriction on use
- Caveats and limitations
- Final value conclusion
- Signature, registration details, and date, if applicable

## Calculation Review Rule

If the document contains tables, schedules, workings, formula outputs, totals, subtotals, per-share values, enterprise value bridges, equity value bridges, option values, or mathematical calculations, check visible mathematical consistency where possible.

Check:

- Totals and subtotals
- Per-share calculations
- Enterprise value to equity value bridge
- Equity value divided by number of shares
- Discounted cash flow totals
- Present value calculations if visible
- Terminal value flow-through if visible
- NAV summary if visible
- ESOP option value summary if visible
- Reconciliation between schedule values and report conclusion
- Rounding consistency
- Unit consistency, such as INR, USD, AED, SGD, million, crore, lakh, per share

Do not calculate beyond the data provided.

If workings are missing, state in the review stage that calculation verification is limited because workings were not provided.

## Valuation Method Review

Check whether the selected method appears logically connected to the purpose and available data.

Common methods include:

- Discounted Cash Flow method
- Net Asset Value method
- Comparable Companies Multiple method
- Comparable Transaction Multiple method
- Market Price method
- Book Value method
- Asset approach
- Income approach
- Market approach
- Option pricing method
- Black-Scholes model, if ESOP/options are involved
- Binomial model, if options are involved

Flag if:

- Method is used but not explained
- Method is selected without reason
- Method appears inconsistent with the purpose
- Multiple methods are mentioned but only one is applied without explanation
- A method is rejected without explanation
- Final value does not reconcile with method output
- Valuation conclusion does not match supporting schedules
- Methodology language is copied generically but not linked to the actual facts
- The purpose of valuation requires a different basis that is not discussed

## ESOP Valuation Review

For ESOP-related valuation documents, check whether the report clearly identifies:

- Purpose of ESOP valuation
- Whether the valuation is for tax, accounting, Companies Act, FEMA, internal management, or commercial purpose
- Applicable scheme or grant
- Grant date
- Vesting date
- Exercise price
- Valuation date
- Report date
- Class of shares or options valued
- Underlying equity value
- Option valuation method, if applicable
- Key assumptions such as volatility, risk-free rate, expected life, dividend yield, exercise price, forfeiture assumption, and market price/FM value, if applicable
- Source of market or financial assumptions
- Whether financial statements or projections are audited, provisional, or management-certified

Flag unclear purpose because ESOP valuation requirements may differ depending on whether the valuation is for accounting, tax, company law, FEMA, or internal reporting.

## Rule 11UA / Tax Valuation Review

When Rule 11UA, Rule 11U, or similar tax valuation reference is mentioned:

- Verify the cited provision from authoritative sources where possible.
- Check whether the document clearly identifies the type of security or asset being valued.
- Check whether the selected method is linked to the relevant rule and factual context.
- Check whether valuation date and transaction date are consistent.
- Check whether supporting financial data is identified.
- Check whether assumptions are clearly stated.
- Do not replace the rule or section unless supported by verification and approved by the user.

Use careful wording:

“The Rule 11UA reference should be verified against the exact nature of the security, transaction, valuation date, and purpose of valuation.”

## FEMA / RBI Valuation Review

For FEMA or RBI-related valuation references, check whether the document identifies:

- Resident/non-resident transaction context
- Issue or transfer of securities
- ODI, FDI, or downstream investment context, if relevant
- Pricing guideline relevance
- Valuation date
- Instrument type
- Applicable RBI/FEMA reference
- Valuation method or pricing basis
- Whether internationally accepted pricing methodology is mentioned, if applicable

Do not assume FEMA applicability unless the document facts support it.

## Companies Act / IBBI / Registered Valuer Review

For Companies Act, IBBI, or Registered Valuer-related valuation documents, check whether the report clearly mentions:

- Whether the valuation is required under Companies Act or related rules
- Whether the valuer is acting as a Registered Valuer
- Relevant asset class
- Registration details, if required
- Independence and conflict statement
- Purpose of valuation
- Scope and limitations
- Methodology
- Key assumptions
- Final conclusion

Flag missing registration, independence, asset class, scope, or valuation date details if material.

## Assumption and Projection Review

Check whether assumptions are:

- Clearly listed
- Consistent with the method used
- Connected to available data
- Reasonable on their face
- Supported by source or management representation
- Applied consistently across schedules
- Not contradicted by the narrative

Flag:

- Unsupported growth assumptions
- Unexplained discount rate
- Missing WACC explanation
- Missing terminal growth explanation
- Inconsistent projection period
- Mismatch between valuation date and financial data date
- Missing source for comparable companies or market multiples
- Missing basis for discounts or premiums
- Contradiction between management projections and valuation conclusion
- Unclear source of volatility, risk-free rate, expected life, or dividend yield in ESOP valuation

## Date and Version Consistency

Check consistency between:

- Engagement date
- Valuation date
- Report date
- Financial statement date
- Projection start date
- Grant date
- Vesting date
- Exercise date
- Transaction date
- Board approval date
- Shareholder approval date
- Effective date
- Appointed date

Flag if the timeline is unclear or inconsistent.

## Jurisdiction Sensitivity

Default to Indian IBBI / Companies Act / Income-tax / FEMA context when the document appears Indian.

If the document involves Singapore, US, UAE, overseas companies, foreign shareholders, or foreign subsidiaries, use `13-cross-border-valuation-source-map.md`.

Do not apply Indian valuation rules to foreign documents unless the facts show Indian law is relevant.

## Output for Valuation Issues

For each valuation issue, show:

- Issue number
- Relevant text/location
- Issue identified
- Why it may matter
- Suggested clarification or wording
- Whether source verification is needed
- Whether calculation verification is limited by missing workings
- Approval required before changing document

## Final Document Rule

Do not insert valuation review concerns, legal cautions, source verification notes, or professional-review notes into the final document unless the user asks.

Keep concerns in the review stage only.
